# Project Instructions

## Korean Documentation Authorship

When editing documentation in this project, preserve author-related context.

- Do not remove or neutralize phrases such as `저자`, `저자의 설계`, `저자의 판단`, `저자의 고민`, or `저자 본인의 설계 노트` merely to make the prose sound more formal.
- The documentation intentionally distinguishes the human author/designer of Janglim from AI assistance.
- Treat this as important authorship and trust context: most of the code that forms Janglim's core structure was designed and written by a human, not generated by AI.
- If wording around author intent feels awkward, improve the sentence while keeping the author/designer as the subject when that is the point of the passage.
- Before finalizing Korean documentation edits, check that author/designer attribution has not been accidentally removed.
